# Will It Run?

Repositorio del proyecto **Will It Run?**.

El codigo de la aplicacion esta dentro de:

```text
Will-It-Run/
```

## Como correrlo

```bash
cd Will-It-Run
npm install
docker compose up -d
npm run seed:all
npm run dev
```

La documentacion tecnica del proyecto esta en
[`Will-It-Run/README.md`](Will-It-Run/README.md).

La guia enfocada en bases de datos esta en
[`Will-It-Run/GUIA_BDD.md`](Will-It-Run/GUIA_BDD.md).
